## Prompt 1 — inorder-acc

Use the scheme-dev skill. Create code/65_q3.rkt starting with `#lang racket/base`. A binary tree is either () or a three-element list (value left right). Write ONE helper only: (inorder-acc tree acc), which returns the inorder list of tree's values placed in front of acc. Do not use append: for a node, first fold the right subtree into acc, then cons the node's value, then fold the left subtree into that. Base case: empty tree returns acc. Add the recursive-reading comment. Nothing else in the file.

## Prompt 2 — print-inorder

Use the scheme-dev skill. In code/65_q3.rkt, add (print-inorder tree): display the result of (inorder-acc tree '()) followed by newline. For '() it must print (). Do not change inorder-acc.

## Prompt 3 — preorder-acc

Use the scheme-dev skill. In code/65_q3.rkt, add (preorder-acc tree acc) returning the preorder list (node, left, right) in front of acc, with no append. For a node: cons the value onto (preorder-acc left (preorder-acc right acc)). Empty tree returns acc. Add the recursive-reading comment. Add nothing else.

## Prompt 4 — postorder-acc

Use the scheme-dev skill. In code/65_q3.rkt, add (postorder-acc tree acc) returning the postorder list (left, right, node) in front of acc, with no append: (postorder-acc left (postorder-acc right (cons value acc))). Empty tree returns acc. Add the recursive-reading comment. Add nothing else.

## Prompt 5 — print-all-traversals

Use the scheme-dev skill. In code/65_q3.rkt, add (print-all-traversals tree): print three lines with display and newline — inorder, preorder, postorder — using the three -acc helpers with '() as the starting accumulator. Use begin if needed. For '() all three lines print ().

## Prompt 6 — tree-height

Use the scheme-dev skill. In code/65_q3.rkt, add (tree-height tree): height of () is 0, height of a node is 1 + (max of the two subtree heights). Use only allowed built-ins (max is allowed). Add the recursive-reading comment.

## Prompt 7 — count-leaves

Use the scheme-dev skill. In code/65_q3.rkt, add (count-leaves tree) using an accumulator helper (count-leaves-acc tree acc). A leaf is a node whose left and right are both (). Empty tree contributes 0. Thread the count through acc: for a non-leaf node, count the left subtree into acc, then the right subtree into that result. Add the recursive-reading comment for both.

Use the scheme-dev skill. In code/65_q3.rkt, add (print-height-and-leaves tree): display (list (tree-height tree) (count-leaves tree)) then newline. '() must print (0 0).

## Prompt 9 — test file
