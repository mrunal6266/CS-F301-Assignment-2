## Prompt 1: prolog-dev skill file
Write a SKILL.md for a skill called `prolog-dev`, with a YAML header (name, description). Include: SWI-Prolog 9.2.9; conventions (snake_case predicates, a comment above each predicate giving its declarative reading); how to run (`swipl -q -f file.pl -g main -t halt`); a self-review checklist (no assert/retract, no global variables, no initialization directive, only lists/apply/yall/aggregate, negation only on ground terms); and common AI mistakes in Prolog (unquoted atoms like Alex or c++, using `\+` on unbound variables, missing cuts causing duplicate output, calling halt).
## Prompt 2: solution structure

It should assign the departments, languages and projects with permutation/2, then check that clue(N, S) holds for every N in Active using forall/2. Don't write the clues yet. Explain why the clues have to be checked after the permutations.
